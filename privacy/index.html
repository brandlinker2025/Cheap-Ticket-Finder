What this site collects directly

This site is a static search page. It has no account signup, no contact form, and — as the site code stands today — it does not run its own analytics and does not ask you for personal data. We do not ask for, and you should never send us, passport numbers, payment-card details, or booking credentials.

What happens in your browser

Your From / To choices and dates are used in your browser only to build Google Flights and official-airline links. When you tap a link you leave this site, and the provider you visit (for example Google Flights or an airline) will process your visit under its own privacy policy, which may include cookies.

Hosting and third-party services

This site is hosted on Vercel and loads shared libraries and fonts from public CDNs (such as Tailwind CSS and Font Awesome via cdnjs) and a public airport database file so the airport list works. Those services may receive a normal web request from your browser (for example your IP address and browser type) as part of delivering the page, under their own policies.

If this changes

If a contact form, analytics, or affiliate tracking is added later, this page will be updated first to say exactly what is collected and why, before it is used.
